Tap a section → content loads. Tap an item → detail expands, sidebar slides away.

Two-Zone Default
Sidebar + content visible together. Full navigation always accessible. This is the resting state.
3️⃣
Three-Zone on Drill-Down
Tapping an item triggers the sidebar to slide away. Content list narrows. Detail zone expands.

Back Restores Sidebar
Back button or left-edge swipe brings the sidebar back. The "Xcode feel" — drill in, pop out.

Visual Direction
Dark Canvas + Liquid Glass Accents
Dark-first design where financial data glows. Glass effects on cards, overlays, and the sidebar create depth without distraction.
🌑
Dark Canvas Base
Rich dark background (#0a0a0f). Data and charts pop. Numbers are the stars, not the UI chrome.
🪟
Intentional Glass
Sidebar has glass material. Cards refract subtly. The effect intensifies as you drill deeper into data — glass = depth.
✨
Semantic Color Glow
Income glows green. Overbudget items pulse soft red. The ambient color tells the financial story before you read a number.
🎯
Hero Metric Focus
One bold number dominates each view. Customizable per user. The first thing you see when you open any tab.
